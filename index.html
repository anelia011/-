01 / КІРІСПЕ

Arduino дегеніміз не?

Arduino — электроника мен бағдарламалауды үйренуге арналған ашық аппараттық платформа.

НЕГІЗГІ ТАҚША

Arduino Uno R3

Микроконтроллер негізіндегі тақша. Датчиктерден мәлімет қабылдап, LED, мотор, дыбыс құрылғысы сияқты бөлшектерді басқарады.

МикроконтроллерATmega328PСандық пиндер14 (6 PWM)Аналог кіріс6Жұмыс жиілігі16 MHz

Сурет/сипаттама: Arduino ресми құжаттамасы.

Жұмыс істеу принципі

Arduino үш негізгі кезеңмен жұмыс істейді:

1
Кіріс (Input)

Датчик қоршаған ортадан ақпарат алады: жарық, температура, қозғалыс.

2
Өңдеу (Process)

Arduino жазылған бағдарлама бойынша мәліметті өңдейді.

3
Шығыс (Output)

Нәтижесінде LED жанады, дыбыс шығады немесе мотор қозғалады.

02 / ҚАЖЕТТІ ҚҰРАЛДАР

Жобаны жинауға не керек?

Әр бөлшектің өз міндеті бар. Алғашқы тәжірибеге осы негізгі жинақ жеткілікті.

Arduino Uno R3

Жобаның басқару орталығы. Код осы тақшаға жүктеледі.

Breadboard

Дәнекерлемей, бөлшектерді уақытша қосуға арналған тақша.

Резистор

Тізбектегі токты шектейді. LED-ті қорғау үшін қолданылады.

LED жарық диоды

Электр тогы өткенде жарық береді. Ұзын аяғы — анод (+), қысқа аяғы — катод (−).

Jumper wires

Arduino, датчик және макет тақшасын электрлік байланыстырады.

USB кабель

Тақшаны компьютерге қосып, код жүктеуге және қуат беруге көмектеседі.

03 / ДАТЧИКТЕР КІТАПХАНАСЫ

Датчиктер және олардың қызметі

Әр датчик белгілі бір физикалық шаманы немесе қоршаған ортадағы өзгерісті анықтайды.

ҚАШЫҚТЫҚ

HC-SR04

Ультрадыбыстық датчик. Дыбыс толқынын жіберіп, оның қайту уақыты арқылы нысанға дейінгі қашықтықты есептейді.

ҚызметіҚашықтық өлшеуПиндерVCC, Trig, Echo, GNDҚолданылуыТұрақ датчигі, робот
ТЕМПЕРАТУРА / ЫЛҒАЛДЫЛЫҚ

DHT11

Ауа температурасын және салыстырмалы ылғалдылығын өлшейді. Көрсеткіштерді жылыжай немесе бөлме мониторингіне қолдануға болады.

Қызметі°C және % өлшеуПиндерVCC, DATA, GNDҚолданылуыАуа райы станциясы
ҚОЗҒАЛЫС

PIR HC-SR501

Адам немесе жануар денесінен шығатын инфрақызыл сәуленің өзгерісін байқайды. Қозғалыс анықталса, OUT сигналы өзгереді.

ҚызметіҚозғалыс анықтауПиндерVCC, OUT, GNDҚолданылуыАвтоматты шам, дабыл
ЖАРЫҚ

LDR фоторезистор

Жарық деңгейіне қарай кедергісі өзгереді. Arduino аналог кірісі арқылы жарықтың салыстырмалы деңгейін оқиды.

ҚызметіЖарықты сезуҚосылуыБөлгіш тізбек + A0ҚолданылуыТүнгі шам
ТОПЫРАҚ

Soil Moisture

Топырақтың ылғалдылық деңгейін шамамен анықтайды. Өсімдікті суару жүйесінің оқу жобасында қолданылады.

ҚызметіТопырақ ылғалыПиндерVCC, GND, AOҚолданылуыАқылды гүл құмырасы
ГАЗ / ТҮТІН

MQ-2

Түтін және кейбір жанғыш газдарға сезімтал. Оқу тәжірибесінде газ деңгейінің өзгерісін бақылауға арналған.

ҚызметіГаз/түтінге сезімталдықПиндерVCC, GND, AO/DOҚолданылуыОқу макеті
Қауіпсіздік: MQ-2 және жалын датчигін нақты газ/өрт қауіпсіздігіне арналған сертификатталған құрылғы орнына қолдануға болмайды. Датчиктерді нұсқаулығына сай, қауіпсіз оқу жағдайында ғана сына.
04 / ҚАДАМ-БА-ҚАДАМ ЖОБА

Алғашқы жоба: автоматты түнгі шам

LDR жарық датчигі мен LED қолданып, жарық азайғанда жанатын шағын құрылғы жасаймыз.

ҚАЖЕТТІ БӨЛШЕКТЕР
  • Arduino Uno
  • LDR фоторезистор
  • 10 кОм резистор (LDR бөлгіш тізбегі үшін)
  • LED және 220–330 Ом резистор
  • Breadboard және jumper сымдары
  • USB кабель
1
LDR-ды қос

LDR-дың бір аяғын 5V-қа, екінші аяғын A0 нүктесіне қос. A0 нүктесінен 10 кОм резистор арқылы GND-ға жалға.

2
LED-ті қос

LED анодын 220–330 Ом резистор арқылы D9-ға, катодын GND-ға жалға.

3
Кодты жүкте

Arduino IDE ішінде тақша мен портты таңдап, кодты Upload батырмасымен жүкте.

ҚОСЫЛУ СЫЗБАСЫ

Arduino Uno + LDR + LED

LDR тізбегіндегі бөлгіштің бағытына байланысты жарық артқанда A0 мәні өсуі де, кемуі де мүмкін. Кодтағы шекті мәнді Serial Monitor арқылы өз тізбегіңе сәйкестендір.
🧪 Осы жобаны Tinkercad-та жасау →
ARDUINO КОДЫ
const int ldrPin = A0;
const int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lightValue = analogRead(ldrPin);
  Serial.println(lightValue);

  if (lightValue < 400) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(200);
}

Шекті 400 мәні — мысал. Өз өлшеуіңе қарай өзгерту керек.

ҚАЛАЙ ТЕКСЕРЕМІЗ?

Жұмысын сынау

  1. Кодты Arduino-ға жүкте.
  2. Serial Monitor ашып, жарық мәнін бақыла.
  3. LDR-ды қолмен жауып, мәннің өзгеруін көр.
  4. LED жанбаса, шекті мәнді түзет.
Қосу алдында сымдарды тексеріп, USB қуатын ажырат. LED-ті резисторсыз қоспа.

Виртуалды симулятор: алдымен экранда жина

Tinkercad Circuits — тегін онлайн симулятор. Бөлшек күйдіру қаупінсіз Arduino тізбегін құрып, кодты жүгіртіп көруге болады.

1

Tinkercad-ты аш

tinkercad.com сайтына тегін тіркел (Google аккаунтымен болады). Circuits бөлімін таңдап, Create new Circuit батырмасын бас.

2

Бөлшектерді жұмыс алаңына қой

Оң жақтағы Components тізімінен іздеу арқылы тап: Arduino Uno R3, Photoresistor, Resistor (10 кΩ және 220 Ω) және Red LED. Тышқанмен сүйреп әкел. Резистордың мәнін таңдап, Resistance өрісінен өзгертуге болады.

3

Сымдарды тарт — біздің сызба бойынша

Бөлшектің аяғын басып, екінші нүктеге дейін апар — сым пайда болады. LDR: бір аяғы 5V-қа, екіншісі A0-ге және 10 кΩ арқылы GND-ға. LED: D9 → 220 Ω → LED ұзын аяғы (+), қысқа аяғы (−) → GND.

4

Кодты қой

Жоғарғы оң жақтағы Code батырмасын бас, режимді Text-ке ауыстыр да, төмендегі кодты қой (бұрынғы мәтінді өшіріп жібер).

5

Симуляцияны іске қос

Start Simulation батырмасын бас. LDR-ді басып, жарық жүгірткісін төмен түсір — A0 мәні 400-ден азайғанда LED жанады. Көрсеткішті Serial Monitor-дан көруге болады.
